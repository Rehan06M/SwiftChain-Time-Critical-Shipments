
# SwiftChain

Intelligent, Time-Critical Logistics and Shipment
Management Platform.

## Technology Stack

Frontend: React + TypeScript + Vite

Backend: Node.js + Express + TypeScript

Planned integrations:
- PostgreSQL + PostGIS
- Redis + BullMQ
- Python + FastAPI
- Socket.IO
- MapLibre GL JS

## Running Locally

### Backend

cd backend

npm install

npm run dev

URL: http://localhost:5000/api/health

### Frontend

cd frontend

npm install

npm run dev

URL: http://localhost:5173
